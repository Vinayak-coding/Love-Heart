# ❤️ Love Heart

A beautiful animated heart made with **HTML, CSS, and JavaScript**. This creative web project uses overlapping text and smooth animations to form a heart shape, creating a romantic visual experience.

## ✨ Features

* ❤️ Animated heart shape created using text.
* 💕 Overlapping words that gradually form a heart.
* 🎨 Attractive design with smooth animations.
* ⏳ Slower animation so viewers can read the displayed text.
* 🔁 Animation repeats three times.
* 📱 Designed as a creative web experience.

## 🛠️ Technologies Used

* **HTML5** — Structures the webpage.
* **CSS3** — Styles the page and creates visual effects.
* **JavaScript** — Controls the animation and its timing.

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Vinayak-coding/Love-Heart.git
   ```

2. Open the project folder:

   ```bash
   cd Love-Heart
   ```

3. Open `index.html` in your browser.

Alternatively, open the folder in Visual Studio Code and use the **Live Server** extension to run the project.
